═══════════════════════════════════════════════════════════════

WHAT THIS DOES:
───────────────

The .htaccess now simply redirects all requests to /public/
The routes.php now handles clean URL routing by redirecting:

  topmost.in         → /web/pages/home.php
  topmost.in/admin   → /web/pages/login.php?type=admin
  topmost.in/owner   → /web/pages/login.php?type=owner
  topmost.in/login   → /web/pages/login.php
  topmost.in/register → /web/pages/register.php

All API endpoints still work normally:
  topmost.in/api/home-data
  topmost.in/api/owner-login
  etc.

WHY THIS WORKS:
───────────────

Simple approach:
1. .htaccess sends everything to public/index.php
2. public/index.php loads routes.php
3. routes.php checks if it's a web route and redirects
4. If not a web route, handles as API endpoint

No complex regex, no router files needed!
