ROOT CAUSE OF "OWNER STATS" AND "OWNER VILLAS" ERRORS:
=======================================================
The routes.php file was passing $userId as a parameter to controller methods,
but those methods don't accept parameters. They get the user ID from the JWT
token internally using $this->requireOwner().

Example of the bug:
  routes.php had: $owner->stats($userId)
  But method is:  public function stats() { ... }

This caused PHP errors which returned HTML instead of JSON.

WHAT WAS WRONG:
===============================================================================

Before: routes.php called $owner->stats($userId)
After:  routes.php calls $owner->stats()

The controller methods internally call $this->requireOwner() which:
1. Validates the JWT token
2. Extracts the user ID from the token
3. Returns the authenticated user data

So passing $userId as parameter was incorrect and caused PHP errors.
