  );
  
  Login with: owner@example.com / password


Issue: "Missing owner_id column"
Fix: Run this SQL in phpMyAdmin:

  ALTER TABLE villas 
  ADD COLUMN owner_id INT DEFAULT NULL,
  ADD INDEX idx_owner_id (owner_id);
  
  ALTER TABLE bookings
  ADD COLUMN owner_id INT DEFAULT NULL,
  ADD INDEX idx_owner_id_bookings (owner_id);

Fix: Look at the HTML error - it will tell you:
  - Which file has the syntax error
  - What line the error is on
  - What the error is
  
  Then fix that file and re-upload it.
