THE PROBLEM:
────────────
When routes.php includes the web pages, the relative paths like
"../helpers/api.php" break because the working directory changes.

THE FIX:
────────
Changed all relative paths to absolute paths using __DIR__

═══════════════════════════════════════════════════════════════

UPLOAD THESE FILES:
───────────────────

1. web/pages/home.php              → /public_html/web/pages/home.php
2. web/pages/login.php             → /public_html/web/pages/login.php
3. web/pages/register.php          → /public_html/web/pages/register.php
4. web/pages/logout.php            → /public_html/web/pages/logout.php
5. web/pages/admin-dashboard.php   → /public_html/web/pages/admin-dashboard.php
6. web/pages/owner-dashboard.php   → /public_html/web/pages/owner-dashboard.php

═══════════════════════════════════════════════════════════════

WHAT WAS CHANGED:
─────────────────

OLD (BROKEN):
  include "../helpers/api.php";
  include "../includes/header.php";
  include "../includes/footer.php";

NEW (FIXED):
  include __DIR__ . "/../helpers/api.php";
  include __DIR__ . "/../includes/header.php";
  include __DIR__ . "/../includes/footer.php";
